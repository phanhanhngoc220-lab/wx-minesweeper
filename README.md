# 小游戏盒子 · 微信小游戏（个人主体版）

一个**无猜扫雷**小游戏，带大厅和“更多游戏”入口（后续可扩展成多游戏聚合），内置激励视频广告接口。

## 导入运行

1. 打开**微信开发者工具** → 导入项目；
2. 目录选本文件夹 `wx-minesweeper`；
3. AppID：
   - 没有账号：选「测试号」或保留 `touristappid`；
   - 有个人主体小游戏：填自己的 AppID；
4. 编译即可在模拟器里玩。

## 操作

| 手势 | 效果 |
| --- | --- |
| 单击未翻开格 | 翻开 |
| **在未翻开格上向下滑** | 插旗 / 取消 |
| 单击已翻开数字 | 快速排雷（旗数等于数字时翻开周围） |
| **双指捏合** | 缩放棋盘（1×–4×） |
| **放大后单指拖动** | 平移棋盘（自动限位，不会拖丢） |
| **双击棋盘** | 复位缩放 |
| **右上角「横屏/竖屏」** | 运行时切换屏幕方向（布局自动重排） |

> 高级/专家棋盘列数多，1× 时格子只有 11px 左右，建议双指放大到 2–3 倍再玩。

横屏切换使用 `wx.setDeviceOrientation`，基础库不支持时会提示；切换后大厅和棋盘都会按新宽高重新排版。

## 目录结构

```
wx-minesweeper/
├── game.js              入口：Canvas 初始化、场景切换、触摸事件
├── game.json            小游戏配置（竖屏、隐藏状态栏）
├── project.config.json  开发者工具项目配置
├── js/
│   ├── config.js        难度、广告位 ID 配置
│   ├── core.js          棋盘生成 + 无猜求解器
│   ├── ui.js            Canvas 绘制工具
│   ├── lobby.js         大厅（难度选择 / 游戏库）
│   ├── minesweeper.js   扫雷玩法
│   └── ads.js           激励视频 / Banner 封装
└── tests/smoke.js       Node 冒烟测试（不需要微信环境）
```

## 广告接入

1. 小游戏累计独立访客 **UV > 500** 后，在 MP 后台「流量主」开通；
2. 「广告位管理」创建**激励视频**和 **Banner**，拿到 `adUnitId`；
3. 填入 `js/config.js`：

```js
AD_UNITS: {
    rewarded: "adunit-xxxxxxxx",
    banner: ""
}
```

- 留空时自动进入开发模式：不展示广告、不阻塞复活流程；
- 失败/中途关闭激励视频不会发奖励，代码里已做 `isEnded` 判断；
- Banner 需要在大厅调用 `ads.showBanner(x, y, width)`，参考 `js/ads.js`。

## 个人主体上线清单（微信）

| 事项 | 说明 |
| --- | --- |
| 主体 | 个人可注册小游戏；不能上架收费游戏 |
| 类目 | 一级固定「游戏」，二级选「休闲」（个人不能选文化互动/角色类/牌类） |
| 软著 | 需《计算机软件著作权登记证书》或电子版权认证 |
| 版号 | **纯广告变现不需要**；一旦有内购就必须有版号 |
| 自查报告 | 游戏自审自查报告（含玩法、内容说明） |
| 备案 | 小程序备案（2023 年起强制） |
| 实名/防沉迷 | 按平台要求接入 |
| 广告 | UV > 500 开通流量主；无刷粉、无严重违规 |

> 政策会调整，提交前以 [微信小游戏官方文档](https://developers.weixin.qq.com/minigame/introduction/) 和 MP 后台提示为准。

## 测试

```bash
node tests/smoke.js
```

会校验五档难度的生成器都能产出「无猜可解」棋盘，并跑一遍核心玩法逻辑。

## 说明

- 纯 Canvas 实现，无第三方引擎依赖，包体很小；
- 无猜生成器在首次点击时后台分帧运行，不会卡住界面；
- 广告、存档、排行榜接口都已留好，方便后续接入云开发。
